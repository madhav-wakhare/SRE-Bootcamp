Argo CD {{ .Chart.AppVersion }} was installed as release "{{ .Release.Name }}" in namespace {{ .Release.Namespace }}.

Every component (application-controller, repo-server, server, redis,
applicationset-controller) is pinned to nodes labelled
type={{ index .Values "argo-cd" "global" "nodeSelector" "type" }}. Confirm:

    kubectl get pods -n {{ .Release.Namespace }} -o wide

This chart only installs the controller. What it deploys is described by the
argocd-apps chart:

    helm upgrade --install argocd-apps ./helm/argocd-apps -n {{ .Release.Namespace }}

Open the UI:

    make argocd-ui        # port-forwards to http://localhost:8090
    make argocd-password  # prints the initial admin password (user: admin)

The server runs with server.insecure=true, so the port-forwarded UI is plain
HTTP. That is fine for a local cluster reached over a tunnel; put a TLS
terminating ingress in front of it anywhere else.

Vault was installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

In-cluster API address (this is what the eso-config chart must point at):

    http://{{ .Release.Name }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

A brand new Vault is sealed and holds no secrets. Finish the setup with:

    make vault-setup      # init, unseal, configure Kubernetes auth, seed secrets

Vault seals itself again on every pod restart, so re-run `make vault-unseal`
after one. Check the status any time with:

    kubectl exec -n {{ .Release.Namespace }} {{ .Release.Name }}-0 -c vault -- vault status
